# Azure Data Factory ETL

Cloud-based ETL solution developed using Azure Data Factory to automate data ingestion, transformation and integration processes for Business Intelligence.

---

## Overview

This project presents the design of a complete ETL architecture using Microsoft Azure services.

The solution automates the ingestion of daily sales data, performs data cleansing and transformations, stores the processed information in Apache Parquet format and integrates the results into Power BI dashboards.

Main components include:

- Azure Blob Storage
- Azure Data Factory
- Data Flow transformations
- Pipeline automation
- Apache Parquet
- Power BI integration
